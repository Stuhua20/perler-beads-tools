# 豆豆工坊 · Bead Studio

一个面向桌面浏览器的拼豆图纸工具：将图片转换为拼豆图纸，调整配色、手动编辑，并导出高清 PNG 或 A4 分页 PDF。

图片读取、配色和导出均在浏览器本地完成，不会上传用户图片，无需 API key、后端服务或数据库。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 图片导入 | 支持拖拽或选择 PNG、JPG、WebP，也可使用内置示例 |
| 品牌色盘 | 支持 Perler Standard 5mm、Artkal S 5mm、Hama Midi 5mm，每品牌收录 32 个基础实色 |
| 图纸生成 | 宽高各 1–200 格，支持锁定比例、原始像素尺寸、自动配色及最多 16 / 24 色 |
| 配色调整 | 使用 CIELAB 感知色差匹配，支持排除颜色、调整透明阈值、合成白色背景 |
| 预览与编辑 | 成品预览、编号施工图、原图切换；支持缩放、拖动、画笔、擦除、整色替换、撤销与重做 |
| 用豆统计 | 实时统计总颗数、颜色数量、各色用量与预估尺寸，图纸短编号对应完整品牌色号 |
| 创意工坊 | 内置 8 张可直接生成和编辑的像素预设，包括雏菊、草莓、吐司、咖啡、猫咪等主题 |
| 图纸导出 | 高清 PNG、A4 分页 PDF，包含施工网格、坐标、颜色编号与用豆清单 |

## 快速开始

### 环境要求

- Node.js 20.19+（20.x），或 22.12 及以上版本。
- npm。
- 桌面浏览器，建议窗口宽度至少 1280px。

当前应用使用 React、TypeScript 和 Vite。仓库保留了原有 Python 项目骨架，启动网页不需要安装 Python。

### 安装与启动

克隆仓库后，在项目根目录执行：

```sh
npm ci
npm run dev -- --port 5173
```

在浏览器中打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。如果端口被占用，以终端显示的地址为准。

### 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 按 `package-lock.json` 安装依赖 |
| `npm run dev` | 启动本地开发服务 |
| `npm run build` | 执行 TypeScript 检查并构建到 `dist/` |
| `npm run preview` | 本地预览已构建的 `dist/`，需先执行构建 |
| `npm test` | 运行配色、分页、PNG 布局、作品状态与预设数据测试 |

## 使用流程

### 1. 选择图片

上传图片或选择内置示例，确认原图后，点击“下一步：调整图纸”。也可以从侧栏进入“创意工坊”，点击预设直接生成图纸并进入编辑。

导入图片最大 20MB，解码后不超过 2500 万像素。透明区域默认不放豆，也可以在设置中选择合成白色背景。

### 2. 调整与编辑

在左侧选择拼豆品牌、格数和颜色数量，修改参数后点击“更新图纸”应用。右侧可切换成品预览、施工图纸或原图，使用画笔、擦除和整色替换微调。

- **整色替换**：选择目标颜色，再点击图纸中原颜色的任意一格；目标选择“留空”可移除该颜色的所有豆子。
- **查看清单**：用豆清单显示完整色号、用量和预估尺寸，图纸中的 `A01` 等编号与清单对应。
- **返回与换图**：返回选图或浏览创意工坊会保留当前作品。替换图片或重新生成前，若存在手动修改，会先提示确认；生成失败时保留原作品。
- **撤销与重做**：支持撤销手动编辑，也可撤销同一素材的参数更新，恢复更新前的作品。

### 3. 下载图纸

点击右上角“下载图纸”，选择 PNG 或 PDF。下载内容以打开下载弹窗时的当前图纸为准；尚未点击“更新图纸”的参数不会应用到导出结果。

> 作品仅保存在当前页面内存中，刷新或关闭页面后不会自动恢复。PNG / PDF 用于查看和制作，不支持重新导入为可编辑项目。

## 导出与打印

### PNG

包含施工网格、坐标、颜色编号与完整用豆清单，适合查看和分享。图纸从数据直接绘制，每格按输出预算分配 24–96px，建议以 100% 原始大小查看编号。

单张 PNG 最多 3200 万像素，最长边 8192px；图纸超限或浏览器无法编码时，请改用分页 PDF。

### PDF

包含作品总览、A4 分页施工图和用豆清单。网格、坐标和格内编号使用矢量绘制；中文标题与清单文字作为图片嵌入，不支持文本搜索。

如需与垫板等比例打印，勾选“等比例垫板打印”，填写实际钉距，并在打印时选择“实际大小 / 100%”。先核对页面上的 50mm 校准标尺；成品尺寸按钉距估算，熨烫后可能变化。

## 构建与部署

```sh
npm ci
npm run build
npm run preview
```

构建后，将 `dist/` 目录部署到静态站点托管服务即可。`npm run preview` 用于本地检查构建结果。

当前代码按站点根路径部署。若部署到 GitHub Pages 的仓库子路径（例如 `/perler-beads-tools/`），需先做两处调整，再重新构建：

- 在 `vite.config.ts` 中配置对应的 `base`。
- 将 `src/components/Sidebar.tsx` 中的 `/assets/bead-daisy.png` 改为基于 `import.meta.env.BASE_URL` 的资源路径，避免插画仍从域名根目录加载。

## 数据来源与适用范围

- 每个品牌的 32 色为本工具选取的基础实色色盘，不代表官方套装或完整颜色目录；各品牌色号独立，不可直接混用。
- RGB 来自 MIT 许可的 BeadColors 社区近似数据，未做实体测色，不代表品牌官方 RGB。屏幕配色请以实体豆色卡为准。
- 透明、珠光、夜光等特殊材质豆色暂未收录，商品库存需自行确认。
- 当前面向电脑端，尚未针对手机端适配。已有 Chromium 桌面交互与布局验证；Edge、Safari 和实际纸张打印仍需独立验证。

数据版本、色号处理与来源记录见 [色盘数据与来源](docs/palette-sources.md)；对应数据许可见 [第三方许可](docs/THIRD_PARTY_LICENSES.txt)。界面设计说明见 [设计文档](docs/design.md)。
